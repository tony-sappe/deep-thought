# Bias overlay

A distorting habit of attention. Name it in one line when it is shaping the frame. Then do the real tool. This page is never the primary tool and never the whole answer.

Source for the set: Daniel Kahneman, *Thinking, Fast and Slow*; the human-nature cluster on Farnam Street. Temporal discounting, present bias, and hyperbolic discounting are one entry.

| Bias | You are seeing it when | The question to ask |
| --- | --- | --- |
| Confirmation | Evidence is being gathered for the current story only. | What observation would make this story fail, and did anyone look? |
| Availability | The vivid recent case is standing in for the distribution. | What is the base rate, and where is the boring majority of cases? |
| Anchoring | The first number is still doing the work of an estimate. | What would this estimate be if that number had never been said? |
| Survivorship | The visible winners are the whole data set. | Where are the cases that failed and left no trace? |
| Planning fallacy | The schedule is the best case told as the expected case. | What happened the last three times this kind of work was estimated? |
| Loss aversion | Avoiding a loss is outweighing a larger gain without anyone saying so. | If we already had the new state, would we pay this much to go back? |
| Present bias | A nearer payoff is beating a larger later one by nearness alone. | What is the choice if both payoffs are moved one year further out? |

Goodhart / Cobra is a structural signal here, not a bias label: the measure became the target, or the incentive increased the thing it pays to reduce. Ask what behavior optimizing the number produces and who checks the actual outcome, then choose a systems tool from [the index](tools/_index.md).

## How to use it

1. Name at most one bias, and the specific move in this problem that shows it.
2. Return to the primary tool's steps. The bias line does not replace them.
3. If the "bias" is actually a system structure (a commons or a burden-shifting fix), drop the bias label and choose the matching page from [the index](tools/_index.md).

Do not list the table in the reply. One line.
