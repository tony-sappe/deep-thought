# Overlap map

Use this when two tools seem to fit. Keep the tool whose axis matches the event. The index is the closed set of pages.

## Keep both when the axes differ

| These stay separate | Because the axes differ |
| --- | --- |
| Eisenhower and Impact–Effort | Urgency × importance is not value × cost. |
| Iceberg, Ladder of Inference, and 5 Whys | Depth of structure, a mind's jump from data to belief, and one linear causal drill. |
| First principles and abstraction laddering | Reduce to truths that survive the current design, versus move up and down the why/how stack. |
| Issue trees, Ishikawa, and connection circles | MECE decomposition, cause categories, and relationship topology. |
| Inversion and premortem | Design the failure of a goal, versus assume a specific plan already failed. |
| Hard Choice and a decision matrix | Kind of choice (impact × comparability, then parity) versus scoring options that share criteria. |
| Balancing loop and reinforcing loop | Goal-seeking versus self-amplifying. A "feedback loop" is not a third tool. |
| Escalation and success to the successful | One page, two shapes. Two actors arming against each other, versus one resource flowing to whoever is already ahead. Neither is a single reinforcing loop. |
| Shifting the burden and fixes that fail | One page. A fix that atrophies the real solution, versus a fix whose delayed side effect brings the problem back. |
| Concept map and causal loop diagram | Labeled relationships without polarity, versus signed links and delays. |
| Map ≠ territory and eigenquestions | Check the frame you have, versus find the question that replaces it. |
| Occam's razor and first principles | Fewer new assumptions in an explanation, versus rebuild from truths. |
| Hanlon's razor and a systems archetype | A person's motive is not required, versus a structure that produces the harm without villains. |
| Cynefin and any tool inside a domain | Sense-making before method. Once the domain is known, stop using Cynefin as the work. |
| OODA and a decision matrix | Tempo under incomplete data, versus scoring when criteria exist. |
| Satisficing and expected value | Stop at good enough, versus compare magnitude × probability. |
| Eisenhower and Theory of Constraints | Personal time triage, versus subordinate the system to its bottleneck. |
| Single-loop action and double-loop learning | Change the action to hit the target, versus change the target's governing variable. |
| Minto and framing diagrams | Conclusion-first prose, versus a shared picture of the choice. |

## Discarded — not tools here

Do not run these, and do not invent a page for them. Route the underlying event to a page that exists.

- Classroom-only routines that do not transfer to adult work. The visible-thinking routines that remain are the communication pages.
- 4Ps, BCG, Challenger Sales, Ikigai-as-life-purpose, happiness models.
- A second copy of a razor that already has a page.
- Marketplace "alternatives" writeups. They are not canon.

If the user asks for one of these by name, say it is not in the guide and classify the event anyway.
