# Shifting the burden

**Job.** Tell a symptomatic fix that wears off from one that also destroys the capacity to apply the real fix.

**Not this.** The fix is simply small. Size is not the distinction. Use this page only when a fix changes the system's later ability to respond, or returns after a delay as a worse problem.

**Diagram.** The symptom, the fundamental solution, the symptomatic fix, and either a delayed worsening (fixes that fail) or an atrophy link (shifting the burden).

**Steps.**
1. Name the symptom people are relieving, and the fundamental problem underneath it.
2. Name the fix in use now.
3. Fixes that fail: the fix reduces the symptom quickly, and after a delay the problem or a side effect returns worse. Draw that delay.
4. Shifting the burden: the fix also weakens the skill, resource, or relationship required for the fundamental solution. Draw that atrophy link. People then need the fix more.
5. Say which of the two you have. A fix that merely fades is not yet a burden shift.
6. Name one move that strengthens the fundamental solution, and which symptomatic relief you will reduce so the atrophy link can weaken.

**Source.** Shifting the burden, and fixes that fail. Peter Senge, *The Fifth Discipline*.
