# Balancing loop

**Job.** Find the goal-seeking structure: a gap drives a corrective action that closes the gap.

**Not this.** The change amplifies itself (reinforcing loop). A named "feedback" with no goal is not yet this tool. If the target slides toward the actual result, say that the goal is eroding. Do not call erosion "correction".

**Diagram.** A loop with an odd number of opposite-direction links, a goal, a gap, and any delay.

**Steps.**
1. Name the goal or limit the system is seeking. If you cannot name it, you may have a reinforcing loop instead.
2. Name the gap between that goal and the current state.
3. Name the action the gap triggers, and the flow or behavior that action changes.
4. Mark the delay. Late correction overshoots. Say so if the delay is long relative to the rate of change.
5. If the goal itself moves to shrink the gap, write that separately. The system is lowering the standard, not reaching it.

**Source.** Balancing (negative) feedback. [Untools](https://untools.co); Donella Meadows, *Thinking in Systems*.
