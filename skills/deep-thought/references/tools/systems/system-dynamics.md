# System dynamics

**Job.** Decide whether a diagram is not enough, and specify the stocks, flows, delays, and behavior over time a model would have to reproduce.

**Not this.** A signed loop will answer the question (causal loop diagram). This page does not invent equations or pretend a prose guess is a simulation. Do not use it to produce a false precision.

**Diagram.** A reference-behavior graph (the variable over time), plus the stocks and flows required to generate that shape.

**Steps.**
1. Say what "how much" or "when" question the diagram cannot answer.
2. Draw the reference behavior: what the important stock has done over time, and what it will do if nothing changes. Label the mode (growth, collapse, oscillation, overshoot and collapse, s-shaped growth).
3. List the stocks, the flows that change them, and the delays. Every feedback path has to touch a stock.
4. A useful model must reproduce the historical mode before anyone tests a policy. If you do not have the history, the next action is measurement, not a model.
5. Name the policy you would test, and the stock whose graph would tell you it worked. Stop there unless a real model is in scope.
6. Do not fill unknown parameters with numbers chosen to produce the ending you prefer.

**Source.** Jay Forrester; John Sterman, *Business Dynamics*. Orientation: [OpenLearn systems thinking](https://www.open.edu/openlearn/systems-thinking-hub).
