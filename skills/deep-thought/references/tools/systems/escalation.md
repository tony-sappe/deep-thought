# Escalation and success to the successful

**Job.** Distinguish two double reinforcing structures: actors arming against each other, versus resources flowing to whoever is already ahead.

**Not this.** A single reinforcing loop (growth or collapse of one quantity). Do not use either name for a team that is merely "on a roll".

**Diagram.** Two reinforcing arms. For escalation, each arm is a response to the other's position. For success to the successful, both arms draw from one allocatable resource.

**Steps.**
1. If each actor increases an activity because the other actor did, call it escalation. Name the threat each one sees and the stock that grows (spend, status, weapons, features, headcount).
2. If a small lead earns more of a shared resource, and that resource widens the lead, call it success to the successful. Name the resource and the two recipients.
3. Draw the two arms. Stop if you can only draw one loop.
4. Escalation: name a coupling that could limit both (a shared constraint or an agreed stop), not a harder push on one arm.
5. Success to the successful: name a rule that allocates some of the resource by a criterion other than current success.
6. Say which shape you have, in one sentence, before recommending a move.

**Source.** Escalation, and success to the successful. Peter Senge, *The Fifth Discipline*.
