# Connection circles

**Job.** Place the changing elements around a circle, draw influence, and discover candidate loops.

**Not this.** You already know the polarities and delays (causal loop diagram), or you only need labeled relationships with no claim of influence over time (concept map). Elements are nouns that can increase or decrease, not one-off events.

**Diagram.** A circle of elements with arrows of influence. Closed paths traced.

**Steps.**
1. List 5 to 10 elements that change in this situation. Use nouns. Cut events and cut solutions.
2. Place them on a circle.
3. Draw an arrow from A to B only when a change in A changes B. No decorative links.
4. Trace every closed path. Each closed path is a candidate loop.
5. Hand each loop you intend to use to the balancing page or the reinforcing page. If nothing closes, stop calling it a dynamic story.

**Source.** Rob Quaden, Alan Ticotsky, and Debra Lyneis, connection circles (Creative Learning Exchange). Worksheet form: [Untools](https://untools.co).
