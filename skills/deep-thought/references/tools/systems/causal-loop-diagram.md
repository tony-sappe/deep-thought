# Causal loop diagram

**Job.** Give a loop signed polarities and delays so you can tell balancing from reinforcing.

**Not this.** You do not yet know what influences what (connection circles or a concept map). A diagram that cannot produce the observed behavior over time is wrong, however neat the signs.

**Diagram.** Named variables, arrows marked same-direction or opposite-direction, delays marked, each loop labeled balancing or reinforcing.

**Steps.**
1. Start from a behavior over time, or from a connection circle you are willing to defend.
2. On each arrow, mark same direction (+) or opposite direction (−). "+" means B moves the same way as A. It does not mean "good".
3. Mark delays where the effect arrives late.
4. Count the opposite-direction links in each closed path. An even count (including zero) is reinforcing. An odd count is balancing.
5. Check the diagram against the behavior over time. If it cannot generate that shape, change the diagram, not the story you wish were true.

**Source.** John Sterman, *Business Dynamics*. Orientation on diagramming: [OpenLearn systems diagramming](https://www.open.edu/openlearn/science-maths-technology/across-the-sciences/systems-thinking-diagramming-tutorials).
