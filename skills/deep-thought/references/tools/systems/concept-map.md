# Concept map

**Job.** Show how the ideas in a situation relate, before you are ready to claim polarities or loops.

**Not this.** You already mean "increases" and "decreases" (causal loop diagram), or you are splitting a question into answerable parts (issue tree). A concept map is not a system dynamics model.

**Diagram.** Concepts as nodes. Every link labeled with a verb phrase. No plus or minus signs.

**Steps.**
1. List the concepts the situation actually uses. Keep names short.
2. Draw a link only where you can label it in words (pays for, blocks, is a kind of, reports to, depends on).
3. Do not add polarity. If the only honest label is "increases" or "decreases", switch tools.
4. Find the concept the others depend on. That is the current center, not necessarily the highest leverage.
5. Stop when a newcomer can read a path aloud as a sentence. Add no link you cannot read aloud.

**Source.** Joseph D. Novak, concept maps: concepts linked by labeled propositions. Worksheet form: [Untools](https://untools.co).
