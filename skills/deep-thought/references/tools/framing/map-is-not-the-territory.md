# Map is not the territory

**Job.** Treat the frame in use as a model built for a purpose, not as the situation itself.

**Not this.** You need a new question (eigenquestions) or a different altitude (abstraction laddering). This page only audits the map you are about to trust.

**Diagram.** The current frame in a box, with what it leaves out written beside it.

**Steps.**
1. Name the map. The diagram, metric, sentence, or model the next decision will trust.
2. State the purpose it was built for.
3. List at least two facts in the situation that this map cannot represent.
4. Decide whether the upcoming decision stays inside that purpose. If it does not, do not decide from this map.
5. Write one change to the map, or name the tool that should replace it.

**Source.** Alfred Korzybski, *Science and Sanity*: the map is not the territory. The audit steps on this page are this guide's check. They are not a chapter of that book. Farnam Street is an index.
