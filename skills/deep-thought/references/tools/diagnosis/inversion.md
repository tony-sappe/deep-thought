# Inversion

**Job.** Design the failure of the goal, then block the moves that would cause it.

**Not this.** You already have a plan and want prospective hindsight on that plan (premortem). Inversion is allowed to recommend not pursuing the goal.

**Diagram.** The inverted goal, a list of moves that guarantee it, and the moves already in progress circled.

**Steps.**
1. State the goal in one sentence.
2. Invert it. How would a determined person guarantee the opposite?
3. List the concrete moves that produce that failure. Include neglect, not only sabotage.
4. Circle the moves already happening.
5. For each circled move, name a block, a removal, or a decision to stop. A list with no change is not the tool.

**Source.** Carl Gustav Jacob Jacobi; Charlie Munger's use of inversion. [James Clear, Inversion](https://jamesclear.com/inversion).
