# Premortem

**Job.** Assume a specific plan has already failed, then surface why, while the plan can still change.

**Not this.** There is no plan yet. Invert the goal instead. A premortem that is not allowed to change the plan is a performance.

**Diagram.** The plan, dated in the future as a failure, with reasons clustered under it.

**Steps.**
1. Restate the plan as a concrete course of action, not a hope.
2. Set a date after the failure. The plan did not succeed. Do not argue that it might.
3. Have each person write reasons for the failure before anyone speaks.
4. Cluster the reasons. Mark the ones you can still change.
5. Change the plan, add a tripwire, or stop. Record which reasons produced no change, so the group can see what it declined.

**Source.** Gary Klein, the premortem; Daniel Kahneman's account of prospective hindsight.
