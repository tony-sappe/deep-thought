# Ishikawa

**Job.** Lay causes out by category so breadth is visible before anyone drills.

**Not this.** You already have one evidenced chain (5 Whys), or you need influence and loops (connection circles). Categories are not a root cause.

**Diagram.** A fishbone. Effect at the head. One bone per category that exists in this system.

**Steps.**
1. Write the effect as something you could observe.
2. Name the bones for this system. The classic set (method, material, machine, person, measurement, environment) is a starting point. Rename any bone that does not exist here, and add one that does.
3. On each bone, list causes that could produce the effect. Mark which are evidenced and which are guesses.
4. If one bone is empty, ask whether that category is absent or unexamined.
5. Either drill one evidenced cause with 5 Whys, or stop because the spread itself shows the missing category.

**Source.** Kaoru Ishikawa. Worksheet form: [Untools](https://untools.co).
