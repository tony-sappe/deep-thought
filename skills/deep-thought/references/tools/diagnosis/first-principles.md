# First principles

**Job.** Strip the problem to statements that stay true if the current design disappears, then rebuild only from those.

**Not this.** You only need a higher or lower altitude and the current truths are fine (abstraction laddering). Also not a MECE split of a trusted problem (issue tree).

**Diagram.** Two columns. Truths that survive. The rebuilt approach beside them. Dropped habits underneath.

**Steps.**
1. Write the current approach and the analogy it leans on ("teams like ours do this").
2. Cross out every statement that is only true because of the current design.
3. Keep statements that remain true anyway. Mark each kept line as an observed fact or a habit you have not tested.
4. Rebuild the smallest approach that satisfies the facts. Do not smuggle a habit back in because it is familiar.
5. List what you did not carry forward.

**Source.** First-principles reasoning; the practical short form in [James Clear, First Principles](https://jamesclear.com/first-principles).
