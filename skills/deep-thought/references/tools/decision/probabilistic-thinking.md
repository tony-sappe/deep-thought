# Probabilistic thinking

**Job.** Replace a yes/no belief with a stated chance, a base rate, and the observation that would move the chance.

**Not this.** You need a weighted comparison of known options (decision matrix) or a single expected-value sum (expected value). This page updates beliefs. It does not pretend a number you made up is data.

**Diagram.** A claim, a probability before the new fact, the fact, and the probability after.

**Steps.**
1. State the claim as something that can turn out true or false.
2. Write the base rate or the prior chance before this case's story. If you have no base rate, say "no base rate" and treat the number you are about to use as a guess.
3. Name the new observation, and whether it is more likely if the claim is true than if it is false.
4. Move the chance up or down in words or in a rough number. Do not move it to 0 or 1 unless the observation logically settles it.
5. Name the next observation that would move it again, and the decision this current chance is good enough to support.

**Source.** Probabilistic thinking. [Farnam Street, mental models](https://fs.blog/mental-models/).
