# Satisficing

**Job.** Set a bar that is good enough, and stop searching when an option clears it.

**Not this.** The values are incommensurable (hard choice), or the cost of a wrong choice is irreversible and you have not priced it (margin of safety, expected value). Satisficing is not an excuse to skip a bar.

**Diagram.** The aspiration line, the options in the order you will meet them, and the first one that clears the line.

**Steps.**
1. Write the conditions an option must meet to be acceptable. Few conditions. Each one checkable.
2. Write what further search costs: time, attention, the option that expires while you compare.
3. Take the options in the order they actually arrive or that you can evaluate. Do not secretly rank the whole set and then pretend you satisficed.
4. Accept the first option that clears the bar.
5. If none clear it, lower the bar on purpose or generate a new option. Do not keep searching an empty shelf and call it rigor.

**Source.** Herbert Simon, satisficing.
