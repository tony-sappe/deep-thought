# WRAP

**Job.** Walk a decision through four moves: widen the options, reality-test the assumptions, attain distance, prepare to be wrong.

**Not this.** A substitute for a matrix when the only missing piece is a score. WRAP is the process around a choice. Skip a move only by saying which one and why it is already done.

**Diagram.** Four boxes in order. Each box has a sentence from this decision, not a definition of the box.

**Steps.**
1. Widen. Add at least one real option beyond the two currently argued, including "stop" or "do this and that" if it is available. Vanishing options do not count.
2. Reality-test. What would you need to see in the world, not in the meeting, to know the favorite assumption is wrong? Go get a piece of it if you can.
3. Attain distance. What would you tell a peer in this spot? What will this look like in a year? Which option is the status-quo bias wearing a spreadsheet?
4. Prepare to be wrong. Set a tripwire: a date or a measure that forces a revisit. Name the small stake you can afford to lose.
5. Then choose. The four moves are not the decision.

**Source.** Chip Heath and Dan Heath, *Decisive*: widen options, reality-test assumptions, attain distance, prepare to be wrong. The four boxes on this page follow that order. A pointer in the eigenquestions handbook is not a second source.
