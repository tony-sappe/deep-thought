# Second-level thinking

**Job.** See whether your expectation differs from the consensus, and whether the current price already reflects that consensus.

**Not this.** You need the later effects of an action that is not about a price or a widely shared expectation. That is second-order thinking. Disagreeing with the crowd is not this tool. The view has to be more right than the consensus already in the price.

**Diagram.** Three marks: your expectation, the consensus, and what the current price reflects.

**Steps.**
1. State the range of likely outcomes you can defend. Do not invent a figure the user did not supply.
2. Say which outcome you expect. State how likely you are to be right only when you already have that basis. Otherwise leave the probability blank.
3. State what the consensus expects, in the words people are actually using.
4. State how your expectation differs from that consensus. If either expectation is unknown, name what is missing; do not treat an unknown view as agreement. If the views do not differ, say so and stop. There is no second-level view yet.
5. Compare the current price with each view only when the price, the expectations, and a basis for relating those expectations to value are available. Use only a price the user gave. A quoted price and general praise do not establish what is priced in. If the evidence is missing, leave the price comparison unresolved, name what is needed, and stop this comparison.
6. With that basis, examine the price implications if the consensus is right and if your view is right. Keep these as conditional scenarios, not established outcomes. If the evidence does not support a price response or a position decision, leave it unresolved.

**Source.** Howard Marks, second-level thinking, in the memo [I Beg to Differ](https://www.oaktreecapital.com/insights/memo/i-beg-to-differ) and in *The Most Important Thing*. He asks for the probability you are right and for how the price moves if each side is right. This page does not invent outcomes, probabilities, or prices. It leaves a probability blank when the user did not supply a basis, and it stops the price comparison when the price or the evidence needed to interpret it is missing.
