# Second-level thinking

**Job.** See whether your expectation differs from the consensus, and whether the current price already reflects that consensus.

**Not this.** You need the later effects of an action that is not about a price or a widely shared expectation. That is second-order thinking. Disagreeing with the crowd is not this tool. The view has to be more right than the consensus already in the price.

**Diagram.** Three marks: your expectation, the consensus, and what the current price reflects.

**Steps.**
1. State the range of likely outcomes you can defend. Do not invent a figure the user did not supply.
2. Say which outcome you expect. State how likely you are to be right only when you already have that basis. Otherwise leave the probability blank.
3. State what the consensus expects, in the words people are actually using.
4. State how your expectation differs from that consensus. If it does not differ, say so and stop. There is no second-level view yet.
5. Say how the current price fits the consensus, and how it fits your view. Use only a price the user gave. If there is no price, say the comparison cannot be finished.
6. Say what that price does if the consensus is right, and what it does if you are right. Keep the position only if your view is more right than the consensus the price already contains.

**Source.** Howard Marks, second-level thinking, in the memo [I Beg to Differ](https://www.oaktreecapital.com/insights/memo/i-beg-to-differ) and in *The Most Important Thing*.
