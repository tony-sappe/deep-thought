# Expected value

**Job.** Compare choices by magnitude times probability, and include the best thing you give up by choosing.

**Not this.** A hard choice between incommensurable values, where a single number fakes a common scale. Also not a full belief update (probabilistic thinking) when you do not yet have the chances. Opportunity cost lives on this page. Do not open a second one.

**Diagram.** For each live option: outcomes, a rough probability, a magnitude in one unit, the product, and the best forgone alternative.

**Steps.**
1. List the real options, including keeping the status quo.
2. For each, write the main outcomes. Give each a probability that sums to about one for that option. Mark any probability that is a pure guess.
3. Put magnitudes in one unit (money, hours, people harmed, days of delay). Do not mix units in the same sum.
4. Multiply and add. The expected value is that sum, not the best case.
5. Opportunity cost: the value of an option includes not taking the best other option. State the forgone option beside the winner.
6. If a guess dominates the sum, the next action is to shrink that guess, not to treat the total as a fact.

**Source.** Probability times magnitude is mathematical expectation, from the seventeenth-century work of Pascal, Fermat, and Huygens. The best option you give up is opportunity cost, a separate economic idea. This page uses both in one pass. Farnam Street and James Clear are indexes.
