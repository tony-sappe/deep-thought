# Decision matrix

**Job.** Compare options on shared criteria. Start unweighted. Add weights only when the unweighted result hinges on a criterion you can justify.

**Not this.** The choice is hard because the values are incommensurable (hard choice), or you do not yet have real options (frame first). Pugh is not a separate tool. The unweighted datum pass is the part taken from him. The source line says what this page changed.

**Diagram.** Options as columns. Criteria as rows. A datum column. Weights only in a second pass, and only if the first pass needs them.

**Steps.**
1. Name the options that exist. Do not invent one to fill the table. Mark one as the datum (the current way, or the option you understand best).
2. Name criteria you would actually regret ignoring. Cut criteria that are the same for every option.
3. Score each cell against the datum: better (+), same (0), worse (−). Do not use a 1–10 scale in this pass.
4. If one option dominates, stop. If the result flips when you drop a single disputed criterion, either resolve that criterion or leave the decision unweighted and say which criterion it hangs on.
5. Add weights only for criteria with a stated reason. Show the unweighted result next to the weighted one. If they disagree, the disagreement is the output, not a prompt to keep tuning weights.

**Source.** Stuart Pugh, "Concept selection: a method that works," in V. Hubka (ed.), *Proceedings of ICED 1981* (Rome: Heurista), and *Total Design* (Addison-Wesley). His controlled convergence compares each concept with one datum: better (+), the same (S), or worse (−). The matrix is iterated. The tally does not crown a winner, the datum can change, and new concepts are added. This page writes "the same" as 0, which is Karl Ulrich and Steven Eppinger's later textbook mark, not Pugh's S. It may stop when one option dominates, which his iteration does not require. The weighted pass is not his method. It is a separate scoring step, used only when the unweighted result hinges on a criterion you can justify. [Untools](https://untools.co) is a worksheet, not the source.
