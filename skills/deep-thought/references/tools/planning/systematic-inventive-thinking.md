# Systematic inventive thinking

**Job.** Invent inside the closed world of the current product by applying one template, instead of brainstorming outward.

**Not this.** A license to add features. The closed world rule: start from components already in the situation. Also not morphological analysis across open parameters (Zwicky box) when you are allowed to import new parts.

**Diagram.** The current components listed. One template applied. The resulting idea in one sentence, marked feasible or not.

**Steps.**
1. List the components and attributes that already exist in the product or the situation. This is the closed world.
2. Pick one template and apply it literally.
   - Subtraction: remove an essential component, then ask what job the remainder can do.
   - Multiplication: copy a component and change the copy in one way.
   - Division: split a component in space or time and rearrange the parts.
   - Task unification: give an existing component a second job.
   - Attribute dependency: create or remove a relationship between two attributes that today are independent (or tied).
3. Write the idea the template produced before you judge it.
4. Keep it only if it serves the job the user hired the product for. A clever rearrangement that does not is a discard.
5. If the template only produced the current design, say so and try one different template. Do not quietly leave the closed world.

**Source.** Systematic inventive thinking (the closed-world templates associated with Goldenberg and colleagues). Indexed by Ness Labs.
