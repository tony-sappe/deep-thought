# Productive Thinking Model

**Job.** Run a creative problem from the mess to a resourced solution, in order, without skipping the question.

**Not this.** A single lens you already know you need (inversion, an issue tree, a matrix). Use this page when the work is "solve this creatively" and the group is about to jump to ideas.

**Diagram.** Six numbered boxes, each with one sentence from this problem. Empty boxes stay empty until you reach them.

**Steps.**
1. What is going on? List the facts of the mess, separate from interpretations.
2. What is success? Describe the future state in observable terms, without naming the solution.
3. What is the question? Write the question that, if answered, would produce that success. This is the eigenquestion of the effort. Stay here if the room is still solving a different question.
4. Generate answers to that question. Quantity first. Do not critique inside this step.
5. Forge the solution. Combine and shape the answers into one approach that could actually be done.
6. Align resources. Who does what, by when, with which support. A forged idea with no owner is still step 5.

**Source.** Tim Hurson, *Think Better* (the Productive Thinking Model). Worksheet form: [Untools](https://untools.co).
