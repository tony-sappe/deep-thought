# Scientific method

**Job.** Turn a belief into a hypothesis, a prediction, a test, and an update.

**Not this.** A thought experiment when contact with the world is the point and a test is available. Also not a retrospective story that cannot be wrong. If you cannot say what result would change your mind, you do not have a hypothesis.

**Diagram.** Hypothesis, prediction, test, result, update. One line each.

**Steps.**
1. State the hypothesis so that it could be false.
2. Predict an observation that is likely if it is true and unlikely if it is false. Put the prediction in writing before you look.
3. Run the smallest test that can produce that observation. Change one thing when you can. Name the confound you are not controlling.
4. Record the result, including a result you do not like.
5. Update the hypothesis or the plan. A test that cannot change the next action was a demo.

**Source.** The hypothesis, prediction, test, and update cycle is the familiar experimental pattern. This page is that short cycle, not a history of the method. James Clear and ModelThinkers are indexes.
