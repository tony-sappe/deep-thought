# Double-loop learning

**Job.** When the usual correction keeps failing, question the governing variable, not only the action.

**Not this.** The first time a straightforward fix has been tried. That is single-loop: change the action to hit the existing goal. Double-loop is for when hitting the goal, or the goal itself, is the problem. The ladder of inference is the cognitive cousin; use it when the issue is one leap from data to belief rather than the standard you are controlling against.

**Diagram.** The action, the result, the governing variable (goal, policy, or master assumption), and a proposed change to that variable.

**Steps.**
1. State the repeated action and the result it keeps producing.
2. State the governing variable: the goal, norm, or assumption the action is trying to satisfy.
3. Single-loop check: is there an action you have not tried that could meet the same governing variable? If yes, this is not yet double-loop.
4. If the variable itself is producing the bad result, name a different governing variable and what observable behavior would change if people adopted it.
5. Make that variable discussable. Argyris's point is that the governing variable is often undiscussable. Write it down where the people who act can argue with it.

**Source.** Chris Argyris, double-loop learning.
