# Evaporating cloud

**Job.** Surface the hidden assumption in a conflict between two necessary conditions, and break the conflict by invalidating that assumption.

**Not this.** A negotiation over positions, or a compromise that splits the difference. The cloud evaporates an assumption. If both needs are real and no assumption yields, the conflict stands. That may be a hard choice, options on a par, which is a different page.

**Diagram.** Five boxes. Objective at the top. Two requirements under it. Two conflicting prerequisites at the bottom. Assumptions written on the arrows.

**Steps.**
1. Name the objective both sides share, even if they describe it differently.
2. Name requirement A and requirement B. Both must be necessary to the objective. If one is a preference, you do not have a cloud.
3. Name prerequisite D and prerequisite D′, the actions that conflict. D and D′ cannot both be done as stated.
4. On each arrow (objective→requirement, requirement→prerequisite, and D versus D′), write the assumption that makes the arrow true.
5. Challenge assumptions until one fails. The solution is an action that serves the requirement without the broken assumption.
6. If no assumption fails, stop and say the conflict stands. Do not invent a compromise and call it an evaporation.

**Source.** Eliyahu Goldratt, the conflict resolution diagram (evaporating cloud). Worksheet form: [Untools](https://untools.co).
