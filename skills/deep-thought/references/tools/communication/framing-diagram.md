# Framing diagram

**Job.** Put the choice on one shared picture so people disagree about the same thing.

**Not this.** The eigenquestion itself. Find the question first if you do not have it. This page draws the choice the question names. Also not a decision matrix: you are not scoring yet. You are checking that the picture is shared.

**Diagram.** One page a newcomer can read: the question, the live options, the tension between them, and what is still undecided.

**Steps.**
1. Write the question in the picture, in the words the eigenquestion pass produced.
2. Draw only the options still alive. Label what each one commits you to.
3. Draw the tension as a tension (a trade, a risk, a disagreement), not as a winner.
4. Mark what is undecided and who would need to decide it.
5. Test the picture on someone who was not in the debate. Where they misread it, the frame is not shared yet. Repair the picture before you return to arguing.

**Source.** A shared picture of the choice, drawn beside an eigenquestion. Shishir Mehrotra’s [eigenquestions handbook](https://docs.superhuman.com/@shishir/eigenquestions-the-art-of-framing-problems) is why the picture sits next to the question. This page does not reproduce that handbook’s color notation.
