# Connect–extend–challenge

**Job.** Take in a new idea by saying what it connects to, what it extends, and what still puzzles you.

**Not this.** A verdict on the person who brought the idea, or a test of whether the idea contradicts a current plan. The routine is about the listener's understanding. Also not a full decision. It prepares one.

**Diagram.** Three columns filled from the same new input: connect, extend, challenge.

**Steps.**
1. State the new input in a sentence, so everyone is responding to the same thing.
2. Connect: how are these ideas connected to what you already know?
3. Extend: what new ideas broadened your thinking or pushed it in a new direction?
4. Challenge: what is still challenging or confusing? What question or puzzle remains? A challenge names what you do not yet understand. It does not score the input as wrong.
5. Keep one item from each column that should change the next conversation. Drop the rest.

**Source.** Harvard Project Zero, Connect, Extend, Challenge. [The routine](https://pz.harvard.edu/resources/connect-extend-challenge).
