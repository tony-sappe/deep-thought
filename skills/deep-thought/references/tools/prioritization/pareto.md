# Pareto

**Job.** Find the small part of the set that produces most of the outcome, and put effort there.

**Not this.** A moral claim that 80/20 must appear. If the distribution is flat, say so and switch tools. Also not impact–effort, which compares projects. Pareto looks inside one outcome for the vital few contributors.

**Diagram.** The outcome, the contributors ranked, and a line where further contributors add little.

**Steps.**
1. Name the outcome in a unit (incidents, revenue, time, defects, complaints).
2. List the contributors and the share of the outcome each one accounts for. If you cannot get shares, get ranks from the record, not from memory of the loud cases.
3. Mark the vital few that account for most of the outcome.
4. If the shares are roughly equal, stop. There is no vital few. Say that.
5. Put the next action on the vital few. Write the long tail down so it is not quietly reintroduced as "also important".

**Source.** Vilfredo Pareto observed unequal distributions, including wealth. Joseph Juran later named that pattern the Pareto principle and popularized 80/20 as the vital few. This page uses the vital few. It does not require 80/20, and it stops when the shares are roughly equal.
