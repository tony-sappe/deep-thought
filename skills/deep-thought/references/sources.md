# Sources

Cite the originator. Indexes are how a tool was found, not the authority for the procedure.

## Canon

- Donella Meadows, *Thinking in Systems*; "Leverage Points: Places to Intervene in a System"; "Dancing with Systems". [Donella Meadows Project](https://donellameadows.org/systems-thinking-resources/)
- Peter Senge, *The Fifth Discipline* (archetypes, ladder of inference via Argyris)
- John Sterman, *Business Dynamics* (stocks, flows, causal loop diagrams)
- Jay Forrester (system dynamics)
- Peter Checkland, soft systems methodology; Stafford Beer, viable system model; Werner Ulrich, critical systems heuristics. Hub used for orientation: [OpenLearn systems thinking](https://www.open.edu/openlearn/systems-thinking-hub)
- Dave Snowden, Cynefin
- John Boyd, OODA
- Eliyahu Goldratt, theory of constraints and the evaporating cloud
- Charlie Munger and the Farnam Street lattice, [mental models](https://fs.blog/mental-models/); James Clear's short essays where a page names them
- Shishir Mehrotra, [Eigenquestions](https://docs.superhuman.com/@shishir/eigenquestions-the-art-of-framing-problems)
- Untools, as the practical worksheet layer: [untools.co](https://untools.co)
- Harvard Project Zero, visible thinking routines only: [thinking routines](https://pz.harvard.edu/thinking-routines)

## Indexes, not authorities

Ness Labs and ModelThinkers are indexes. Use them to discover a tool. Cite the originator on the page.

Each tool page names the source to print in the reply. Do not swap in a blog paraphrase when the page names the originator.
